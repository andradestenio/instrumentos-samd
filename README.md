# Instrumentos IAEC-AD, SPICT-BR e PPS

Aplicação estática em HTML, CSS e JavaScript, para preenchimento e impressão/PDF no navegador.

## Publicação
1. Crie um repositório GitHub e envie `index.html` e `vercel.json` à raiz.
2. No Vercel, escolha Add New > Project > Import Git Repository.
3. Selecione o repositório. Framework Preset: Other. Sem build command; Output Directory: padrão.
4. Clique Deploy.

## Privacidade
Esta versão não utiliza backend nem banco de dados. Não coloque dados reais de pacientes em commits, issues ou arquivos do repositório. Avalie requisitos LGPD e políticas institucionais antes do uso assistencial.
